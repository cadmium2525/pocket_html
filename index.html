    A QUICK GUIDE

    Pocket HTML の使い方

    iPhoneで開く

    HTMLを「ファイル」アプリに保存し、このページの「ファイルを選んで開く」から選択します。iCloud Driveのファイルも選べます。よく使う場合はSafariの共有メニューから「ホーム画面に追加」すると便利です。

    画像や音声が別ファイルのとき

    HTMLと画像・CSS・JavaScriptなどを、フォルダ構成を保ったまま1つのZIPにしてください。ZIP内にHTMLが複数あれば、開くページを選べます。PCでは関連ファイルをまとめて選択する方法も使えます。読み込めるのは合計32MB・600ファイルまでです（ZIPは展開後も32MBまで）。パスワード付きZIPには対応していません。

    ブラウザゲームについて

    JavaScript、Canvas、WebGL、タッチ入力を使うゲームを実行できます。画面いっぱいに表示するボタンも使えます。音声はゲーム内でのタップが必要です。外部ライブラリを読み込むゲームにはインターネット接続が必要です。

    HTTP配信が必要なゲーム

    python -m http.serverなどで配信して遊ぶゲームや、Viteのビルド済みdistを、フォルダ構成を保ったZIPで開きます。表示枠の「HTTP」から、信頼するファイルでHTTPモードを選択してください。ZIP内をブラウザ内だけでHTTP配信するため、サーバー契約やアップロードは不要です。

    HTTPモードでは、通常のURLによるモジュール・Worker・WebAssembly・IndexedDBなどを利用できます。ファイルのプログラムはViewerと同じサイトとして動くため、保存済みファイルにもアクセスできる状態になります。自作など信頼できるファイルだけで利用してください。

    どんなゲームでも動くわけではありません。Node.js・PHP・Pythonのサーバー処理、外部API、ゲーム自身のService Worker、SharedArrayBufferを使う複数スレッドなどは実行環境が必要です。HTTPモードもそれらのサーバーを起動する機能ではありません。キーボード専用のゲームには外部キーボードが必要です。

    ファイルとセーブデータ

    選んだファイルをViewerからサーバーに送ることはありません。ただし、HTML自身の外部通信は実行されます。信頼できるファイルを開いてください。「この端末に保存」がオンなら、最近の5件をブラウザ内に保存します（1件32MBまで）。

    通常表示ではlocalStorage・sessionStorageを互換機能で処理します。HTTPモードではブラウザの保存領域を利用するため、通常表示とは別のセーブになります。ブラウザのデータ削除やプライベートモードでは履歴・セーブが消える場合があります。履歴の削除は保存したファイルを削除します。

    HTTP配信で実行する

    ブラウザ内でZIPのファイルをHTTP配信します。モジュールやWorkerなどを、通常のWebサイトと同じURLで読み込めます。サーバーへのアップロードや有料サービスの契約はありません。

    このモードのプログラムは、Viewerの保存領域にもアクセスできます。自作など、内容を信頼できるファイルだけで利用してください。
